### Hi, I'm Aleksandr 👋

**QA Automation Engineer (AQA)** — Python + Playwright and Java + Selenide for E2E and API testing; Go for backend tooling.

### 🧪 What I do

- **UI/E2E automation** — Playwright (primary) & Selenium WebDriver with pytest: Page Object Model, fixtures, parametrize, smoke/regress tags, UI reruns, screenshots & Playwright traces on failure
- **API testing** — REST, JSON, auth, webhooks, schema validation, negative cases; payment & delivery service APIs, OpenCart e-commerce integrations
- **Backend for tests** — build REST services in Python and Go (SSE streaming), so I test more than "200 OK"
- **Hardware testing** — industrial embedded system (current job): sensor validation, safety & fault scenarios on Embedded Linux
- **Web3 testnet tooling** — Ethereum Sepolia ↔ L2 bridges (Arbitrum/Base Sepolia), RPC, EIP-1559, Web3.py
- **QA practices** — test cases, checklists, bug reports, requirements analysis, RCA
- **CI** — GitHub Actions on every push: API + UI against an ephemeral Docker stand, Allure / JUnit reports, [live Allure report](https://g-alex.github.io/pytest-playwright-ecommerce/)
